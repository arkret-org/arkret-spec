# Contrix Machine-Executable Artifacts

This directory holds the canonical machine-readable outputs referenced by `_todos.md`:

- `schemas/`: JSON Schema contracts for core objects, sync state, blob/media, push, and identity.
- `openapi/`: unified OpenAPI 3.1 service contract.
- `bindings/`: transport-neutral non-HTTP binding registry.
- `fixtures/`: official conformance vectors for encoding, state resolution, redaction, capability, sync, federation, and privacy/security.
- `profiles/`: implementation and deployment profile manifests.
- `registry/`: schema and operation registries shared across artifacts.
