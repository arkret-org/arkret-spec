# Standard Object Types

Standard Entity types in the first profile:

- `board`
- `collection`
- `task`
- `message`
- `topic`
- `channel`
- `document`
- `file`
- `memory`
- `run`
- `actor_profile`
- `poll`
- `social_post`
- `social_feed`
- `social_circle`

These are semantic conventions over the core Entity / Relation / Event model. They do not introduce separate protocol roots.
