# Transport Bindings

This file is the English placeholder for the detailed Chinese draft in `../zh/transport-bindings.md`.

Contrix core is not bound to REST APIs. HTTP/JSON is the default interoperability binding, while equivalent gRPC, WebSocket, SSE, message queue, libp2p, GraphQL, or IPC bindings may be used if they preserve the same operation semantics, authentication, authorization, idempotency, pagination, streaming, error, and flow-control behavior.
